# PRD-04: Indexing Implementation Plan

**Goal:** Create Pinecone hybrid search index with dense (Voyage) and sparse (BM25) vectors

**Architecture:** Voyage AI embeddings + Pinecone native hybrid search

**Tech Stack:** Voyage AI API, Pinecone Serverless, pinecone-text for BM25

---

## Task 1: Create Embedding Generator

**Files:**
- Create: `src/indexing/embeddings.py`

**Implementation:**
Generate dense embeddings using Voyage AI voyage-3

**Steps:**
1. Create VoyageEmbedder class
2. Implement batch embedding with rate limiting
3. Use `input_type="document"` for chunks
4. Handle API errors gracefully
5. Add progress logging

**Verification:**
```python
from src.indexing.embeddings import VoyageEmbedder
embedder = VoyageEmbedder()
embeddings = embedder.embed_chunks(chunks[:10])

```

**Commit:** `feat: add Voyage AI embedding generator`

## Task 2: Create Sparse Vector Generator

**Files:**
- Create: `src/indexing/sparse_encoder.py`

**Implementation:**
Generate BM25-style sparse vectors for hybrid search

**Steps:**
1. Create SparseEncoder class using pinecone-text
2. Fit encoder on corpus
3. Generate sparse vectors in Pinecone format
4. Save fitted encoder for query-time use
5. Handle tokenization properly

**Verification:**
```python
from src.indexing.sparse_encoder import SparseEncoder
encoder = SparseEncoder()
encoder.fit(chunk_texts)
sparse = encoder.encode(chunk_texts[0])
print(f"Sparse vector: indices={len(sparse['indices'])}, values={len(sparse['values'])}")
```

**Commit:** `feat: add BM25 sparse vector encoder`

## Notes

- Voyage AI free tier: 200M tokens/month (sufficient for 20 docs)
- Pinecone free tier: 2GB storage, unlimited queries
- BM25 encoder: Use pinecone-text library (simpler than custom)
- Batch sizes: 128 for embeddings, 100 for upsertion
- Rate limiting: Implement exponential backoff for APIs
